YT Uploader

YT Uploader is a private tool that publishes and manages videos for two YouTube channels run by its owner: Marblephonic (marble-melody Shorts) and Signpost (geopolitics explainers).

It uploads the owner's own videos, schedules them, sets thumbnails and channel details, reads the channels' own analytics, and reads and replies to comments on those channels. It is not offered to the public and does not access anyone else's account. It uses YouTube API Services.
